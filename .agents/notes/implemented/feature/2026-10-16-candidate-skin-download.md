# Agent Note: 官网下载候选窗皮肤

Status: implemented

## Problem

官网能浏览 PC 候选窗皮肤，也已有账号会话，但卡片只提供收藏和评分。用户必须再到客户端搜索一次，无法从官网取得皮肤文件。

## Decision

登录要求由[公开皮肤无需登录](2026-10-16-public-skin-download-without-login.md)取代；本篇保留原接口选择与 ZIP 安全约束的理由，原登录流程及其验证不代表当前行为。

候选窗皮肤卡片提供下载按钮，未登录时沿用网站登录入口。登录后通过现有同源账号代理 POST `/v1/community/candidate-skins/{id}/download`，保留后端的权限与下载计数。在浏览器按原始 `skin.toml` 和图片构建 ZIP，顶层目录为 `package_id`，解压后可直接复制到客户端皮肤目录。私有作品只通过拥有者会话下载，不进入公共缓存。

下载模块只在点击后加载。归档前检查返回的作品 ID、目录与资源路径、文件数量和体积，拒绝路径穿越、绝对路径和清单覆盖。图片不重新编码，清单及其中授权信息原样保留。

## Alternatives considered

让 Pages Function 直接返回 ZIP 可以减少浏览器打包工作，但需要新增二进制接口并重复会话轮换与错误处理。现有账号代理已经具备权限和刷新能力，最多 2 MiB 的图片适合浏览器打包，因此复用现有 JSON 请求。

## Consequences

广场、收藏和「我的皮肤」共用候选窗卡片，因此三处都有下载入口。用户无需再次到客户端按名称搜索；代价是桌面宿主读取文件夹而非 ZIP，页面须明确解压和复制步骤。下载权限继续由后端控制，官网不提供匿名绕过。

ZIP 使用按需加载的 `fflate`，原图已经压缩，因此采用存储模式避免重复压缩占用主线程；新增依赖的 MIT 原文随站点发布，固定来源与摘要见 README 和锁文件。下载链接交给浏览器后延迟释放，不在点击后立即撤销 Blob URL。

## Verification

- `pnpm test`、`pnpm lint`、`pnpm exec tsc --noEmit`、Python 自动化限制测试和完整 `pnpm build` 通过。
- `scripts/community-skins.test.mjs` 解包核对原始清单和全部图片，覆盖错误作品 ID、非法路径、清单覆盖、文件数量、单图与整包体积；通过会话代理的 POST 与错误响应也有验证。
- 本地 Chrome 在生产 CSP 下用合成接口数据验证：未登录打开登录窗口，登录下载真实 ZIP、失败重试、下载中禁用按钮、私有作品下载；1280px 简体和 390px 繁体均通过，没有页面异常或横向溢出。未使用真实账号，也未声称生产部署或生产账号下载已验证。
