# Agent Note: 官网公开皮肤下载不要求登录

Status: implemented

## Problem

公开 PC 皮肤下载不需要账号。原实现因为复用账号下载接口，在卡片上主动打开登录窗口，把文件下载与收藏、评分的身份要求绑在一起。

## Decision

候选窗皮肤卡片点击即下载，不读取账号状态，也不在错误时打开登录窗口。POST 仍通过同源代理转发：无 cookie 时匿名请求，有有效会话时保留后端的按账号下载去重。权限由后端统一按作品可见性判断，私有和已下架作品仍仅拥有者可下载。页面使用说明和简繁 SEO 均明确公开电脑皮肤无需登录。

本决定取代[原下载方案](2026-10-16-candidate-skin-download.md)中「未登录先登录」的要求，其 ZIP 结构、包校验、按需加载和文件释放决定继续有效。后端必须先上线允许匿名下载的接口。

## Alternatives considered

只移除前端登录入口可以简化页面，但旧后端仍返回 401，无法完成下载；因此后端接口一同放宽公开作品的访问权限。给匿名访客创建临时账号可以复用原统计，但增加身份状态且违背无需登录的意图；直接匿名下载，不为统计制造账号。

## Consequences

未登录访客也能下载完整 ZIP，收藏和评分继续要求账号。匿名下载不计入按账号去重的下载人数，统计不表示总文件下载次数。登录会话下仍保留原有代理和私有包权限，错误显示可重试提示。

## Verification

自动化测试通过真实同源代理分别验证带 cookie 和不带 cookie 的 POST、ZIP 内容与链接清理；Chrome 使用合成接口和生产 CSP 验证未登录下载、失败重试与私有卡片。完整门禁结果记录在 PR。
