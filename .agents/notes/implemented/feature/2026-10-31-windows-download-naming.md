# Agent Note: Windows 下载入口改用正式版与新版预览

Status: implemented

## Problem

下载页把 `msime-windows` 的正式产品线称为「纯净版」，把 `msime` 仓库的 Rust 重写预览称为「联网版」。这两个名称暗示的是是否联网，但两条产品线都支持本地输入，云候选、AI 联想、翻译、语音和更新检查才分别决定联网行为；用户因此反复询问两者区别。

## Decision

官网把 Windows 10/11 的两个入口显示为「正式版」和「新版预览」。正式版继续读取 `msime-windows` 的发布清单，新版预览继续读取 `msime` 的 `experimental` 槽位；内部 `pure`、`online` 查询值保持不变，旧链接和统计协议不受影响。下载页在入口下直接说明两条产品线的来源、测试状态、本地输入能力、联网功能开关和独立数据目录；新版预览的操作提示也使用新名称。首页、下载统计、安装指南标题和项目 README 统一使用新名称。

## Alternatives considered

保留「纯净版/联网版」并只在 FAQ 解释，改动最小，但用户在下载入口做选择时仍会先看到误导性名称，因此不采用。把两者合并为一个「Windows」入口会隐藏两套独立版本序列、签名状态和安装数据目录，无法让用户明确选择，因此也不采用。

## Consequences

用户可以从名称直接看出推荐的正式版和供测试的新实现，不会把产品线名称误认为隐私或联网开关。旧的 `windows=pure|online|win7` 查询参数继续兼容，统计字段和发布清单无需迁移；历史决策笔记中的旧称只保留为当时的实现记录。

## Verification

更新简体和繁体下载页静态输出测试、下载适配测试及首页/统计文案，运行仓库的 lint、单元测试和完整构建确认两个入口、旧查询链接和繁体页面均可渲染。
