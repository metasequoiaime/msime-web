# 隐私政策

本页说明输入法的本地数据、联网功能，以及浏览官网和提交反馈时涉及的数据。各平台的功能与默认设置不同，请查看你所用平台的说明。

## 本地输入与联网功能

拼音转换、候选排序和词频学习在本机完成。云候选、AI 联想、在线翻译、云端语音识别、匿名使用统计、账号和更新检查可能联网，具体取决于平台与设置。

| 功能 | Windows 正式版 | macOS | Linux |
| --- | --- | --- | --- |
| 云候选 | 默认开启，首次安装可取消勾选 | 新装默认关闭，首次激活时询问，默认不启用 | 新装默认关闭，首次配置时询问，默认不勾选 |
| AI 候选联想 | 配置有效凭据后可用 | 填写自己的密钥后才联网 | 默认关闭，需配置服务 |
| 候选翻译 | 在线翻译需配置腾讯云凭据 | 默认不联网，需在设置中选择翻译服务 | 默认不联网，需在设置中选择翻译服务 |
| 语音输入 | 需配置服务并主动触发 | 主动触发，可选云端服务、本地模型或系统识别 | 主动触发，可选云端服务或本地模型 |
| 匿名使用统计 | 不发送 | 默认开启，可关闭 | 默认开启，可关闭 |
| 检查更新 | 手动点击时联网 | 手动点击时联网 | 手动点击时联网 |

Windows 正式版的部分联网功能开关默认开启，但随包凭据为占位符；在填入有效凭据前，AI 联想、在线翻译和语音服务不会因此发出请求。云候选不需要 API 凭据。

下载页的「Windows 新版预览」与上表的 Windows 正式版是两个不同的程序，默认设置也不同：云候选新装默认关闭，安装器「联网功能」页的勾选框默认不勾；匿名使用统计默认开启，可在设置的「关于」页关闭；安装完成后首次启动时注册一个匿名账号；后台约每天向 GitHub Releases 接口查一次新版本，只弹通知、不下载安装。AI 联想、在线翻译和云端语音识别默认没有凭据，填入自己的凭据并选择服务后才联网。

## 会向服务商发送什么

- **云候选**：开启后向 Google input-tools 服务发送当前输入的拼写，以获取额外候选。该请求不包含已提交的正文、词库或学习记录。Windows 正式版默认开启；Windows 新版预览、macOS、Linux 与移动端新装默认关闭，需要你在首次询问或设置中打开，升级沿用已有设置。
- **AI 联想**：向配置的服务商发送拼写及功能所需的上下文。Linux 会附带当前输入框里最近由输入法上屏的文字（最多 1 KB），切换焦点或在密码等私密输入框中时清空。
- **在线翻译**：向所选翻译服务发送需要翻译的候选文本。选择「水杉账号」时，当前页的中文候选词会发送到水杉服务（api.msime.app）；各平台新装都不默认选中它，只有你主动选择才发送，升级沿用已有设置。本地词典翻译不需要联网。
- **云端语音识别**：向所选服务发送录音。若开启文字润色，识别结果还会发送到配置的文字服务。
- **匿名使用统计**：Windows 新版预览、macOS、Linux、iOS、Android 与 HarmonyOS 默认向水杉服务（api.msime.app）发送每天一条活跃记录、会话记录和崩溃时的错误摘要与调用栈，附带平台、版本号和一个随机生成的安装编号，不含输入内容、候选、剪贴板、账号或硬件信息。macOS 与 Linux 可在设置「关于 → 许可与隐私 → 匿名使用统计」关闭，Windows 新版预览在设置的「关于」页关闭，移动端在 App 的关于或设置页中关闭，关闭后同时清空本机待发送的记录。HarmonyOS 在你同意首次启动的隐私授权弹窗之前不发送。Windows 正式版不发送统计。
- **匿名账号**：Windows 新版预览、macOS、Linux、iOS 与 Android 在安装后首次启动时（Linux 在安装或首次配置时），HarmonyOS 在你同意首次启动的隐私授权弹窗之后，用本机随机生成的标识和口令向水杉服务注册一个匿名账号，供候选翻译等功能使用，不发送输入内容或设备信息。
- **服务公告**：打开设置窗口时读取一次公告列表，不带凭据和安装编号。
- **更新检查**：Windows 正式版请求本站的更新清单；Windows 新版预览在后台约每天查一次 GitHub Releases 接口，发现新版本时只弹通知；macOS 与 Linux 在点击「检查更新」时请求 GitHub Releases 接口。

选择本地模型时，音频在本机识别，只有在设置中下载模型时会从 GitHub（或你配置的镜像）下载文件；但如果同时开启在线文字润色，识别出的文字仍会发送到润色服务。第三方服务通常也能获得 IP 地址和常规请求信息，后续处理与保存方式以其隐私政策为准。

## 如何减少联网

- **Windows 正式版**：在“设置 → 输入”中关闭云候选，并关闭 AI 辅助、在线翻译与语音输入。更新检查仅在主动点击时进行。
- **Windows 新版预览**：新装时云联想已关闭；若曾打开，在设置中关闭云联想，并在「关于」页关闭匿名使用统计。
- **macOS 与 Linux**：新装时云联想已关闭、翻译服务未选择；若曾打开，在设置中关闭云联想与 AI 联想，翻译服务改选「不使用在线翻译」，并在「关于 → 许可与隐私」中关闭匿名使用统计。需要语音输入时选择本地模型并关闭在线文字润色（macOS 的设置步骤见 [macOS 语音输入指南](/docs/macos-voice/)）。

配置文件与具体操作见各平台[使用指南](/docs/windows/)及下方的原始隐私说明。

## 本机数据与 API 凭据

设置、学习记录和用户词库保存在当前用户目录，受该账号的文件权限保护。备份、同步或分享这些文件前，请检查是否包含个人词条、日志或服务凭据。

- **Windows 正式版**：数据位于 `%LOCALAPPDATA%\metasequoiaime\`；API 凭据以明文保存在 `config.toml` 中。
- **macOS**：设置与数据位于 `~/Library/Application Support/app.msime.macos/`，账号会话保存在其中仅本人可读写的 `account-session.json`。
- **Linux**：配置和数据位于 `~/.config/msime-client/` 等用户 XDG 目录；服务商凭据和账号会话保存在仅当前用户可读写的文件中，不加密。

剪贴板历史默认关闭，开启后会在本机保存复制内容。请勿公开分享含凭据的配置文件。

各平台对日志、学习记录及数据清理的具体行为，请以原始隐私说明为准；官网访问和反馈表单另按下文处理。

## 浏览官网

官网通过 Cloudflare 提供服务，页面请求会涉及 IP 地址和常规访问、安全处理信息。社区统计由本站提供，贡献者头像从 GitHub 加载。点击第三方链接后，将进入相应网站。

官网用 Cloudflare Web Analytics 统计访问量：页面会加载 Cloudflare 的统计脚本，向 Cloudflare 报告访问的页面地址、来源页、浏览器类型和页面加载耗时。它不使用 Cookie，也不在浏览器里保存任何标识，不读取你在页面里输入的内容。

官网另使用自托管 Umami（`umami.yldm.tech`）统计页面访问、发布链接中的 UTM 来源与下载按钮点击。统计包含页面路径、标题、来源网站、浏览器语言和屏幕尺寸；除发布活动参数外，地址中的搜索参数和锚点会在发送前移除，外站来源只保留网站域名。下载点击附带平台、渠道、版本和公开安装包文件名，它不代表文件已下载完成或应用已安装。Umami 不接收账号标识、表单内容或网页输入法中的文字，不设置统计 Cookie；活动来源只在本次打开页面的内存中保留。浏览器开启「请勿跟踪」（DNT）时，不加载这项统计。连接仍会经过服务器和 Cloudflare，因此它们可见常规网络请求信息。

顶栏的网页输入法在你的浏览器里运行：引擎、词库和辅助码表从本站下载，打字、组词和候选排序都在本机完成，输入的内容不会发送到任何服务器。选择的方案、双拼布局和辅助码保存在本机浏览器中，在顶栏的键盘图标里选「关闭」即可改用系统输入法。

点击下载页的「蓝奏云盘」链接时，浏览器会向水杉服务（api.msime.app）发送一条匿名下载计数，内容只有平台（Windows）、版本号、安装包文件名、渠道（蓝奏云盘）和一个每次点击随机生成的编号，不含 Cookie、账号或设备标识；请求本身会经过服务器，因此服务器会看到 IP 地址，但不随计数保存。上述后端下载计数不重复记录 GitHub 下载；GitHub 按钮的匿名点击另由 Umami 记录。

页面顶部的公告由本站从水杉服务读取后显示，读取时不发送访客信息。关闭某条公告后，它的编号保存在本机浏览器中，用于不再显示这条公告，不会上传。

## 官网账号与同步数据

官网登录目前提供 Google 登录和邮箱验证码登录，实际开放的方式以登录窗口显示为准。登录只需要完成身份验证，不会把 Google 密码交给水杉；邮箱登录也不会把验证码明文保存到数据库。

登录时涉及的信息和保存方式如下：

- **Google 登录**：Google Identity Services 在浏览器中完成验证，官网收到本次登录的 ID Token 后，经本站的 Cloudflare Pages Functions 转给水杉服务（`api.msime.app`）校验。服务端保存 Google 提供方和稳定的账号标识；如果 Google 返回已验证邮箱、昵称或头像地址，也会保存这些资料，用于识别账号和显示账号资料。官网不会保存 Google 密码。
- **邮箱验证码登录**：官网把你填写的邮箱地址发送给水杉服务，请它发送验证码。服务端临时保存邮箱、验证码摘要、挑战编号和过期时间；验证码有效期为 5 分钟，正文不写入数据库，挑战过期后由每小时清理任务删除。登录成功后，邮箱作为该账号的登录身份保存。
- **账号资料**：服务端为账号分配内部 ID，并保存昵称、创建时间、已绑定的登录方式，以及（有的话）已验证邮箱和头像地址。你在「我的」页面修改昵称会更新服务端资料；自定义头像由 App 上传到水杉的对象存储（`media.msime.app`）。
- **登录状态**：访问凭证和刷新凭证分别放在本站域下的 `HttpOnly`、`Secure`、`SameSite=Lax` Cookie 中，网页脚本读不到令牌。访问凭证 15 分钟过期，会话最长 30 天；服务端数据库只保存令牌摘要和会话资料，不保存明文令牌。浏览器本地的 `msime-account` 只是一位已登录提示，不含账号或令牌。

在水杉输入法 App 中登录时，可用的方式以各平台登录界面显示为准，除上面的 Google 和邮箱验证码外还可能涉及：

- **App 中的 Google 登录**：保存的资料与官网 Google 登录相同。桌面端经浏览器授权登录时，服务端还会加密保存 Google 返回的刷新令牌，密钥不在数据库中，随该登录身份一起删除。
- **Apple 登录**：Apple 在设备或浏览器中完成验证，水杉服务校验 Apple 签发的 ID Token 后，保存 Apple 提供方和稳定的账号标识。经网页完成的 Apple 登录（例如 Android）中，如果 Apple 返回了邮箱（可能是 Apple 的隐藏邮箱转发地址）和姓名，也会一并保存。水杉不会获得你的 Apple ID 密码。
- **华为账号登录**（HarmonyOS）：华为账号服务在设备上完成授权，App 把华为签发的 ID Token 交给水杉服务校验。服务端只保存华为账号提供方和 ID Token 中的 `sub`（同一开发者名下各应用相同的 UnionID），不保存华为账号的昵称、头像、手机号或邮箱，也不会获得华为账号密码。
- **手机号验证码登录**：目前各平台都没有开放。开放后，验证码经阿里云短信服务发送到你填写的手机号，手机号作为该账号的登录身份保存，验证码的处理方式与邮箱验证码相同。

官网页面只请求本站的 `/api/` 路径；Cloudflare Pages Functions 再把账号请求转发到 `api.msime.app`，并代为携带会话。账号资料和同步内容不写入 Cloudflare Pages 的静态文件。水杉服务会看到请求所需的常规网络信息（例如 IP 地址），用于连接和限流。

账号数据的去向、用途和保留时间如下：

| 数据 | 保存位置 | 用途 | 保留方式 |
| --- | --- | --- | --- |
| 账号 ID、昵称、创建时间、登录身份、已验证邮箱和头像资料 | `api.msime.app` 的用户数据库；自定义头像另存于 `media.msime.app` | 登录、识别账号、显示账号资料和绑定登录方式 | 不按时间自动过期，直到修改、删除账号或删除头像；更换头像时旧对象随即删除 |
| 个人偏好、同步词库、候选位置与选择记录、快捷短语 | `api.msime.app` 的用户同步数据 | 在已登录的 App 设备之间同步 | 不按时间自动过期；删除对应数据分区或注销账号后删除 |
| 云剪贴板 | `api.msime.app` 的用户数据库 | 在设备之间同步剪贴板 | 文本在设备端加密，服务端只保存密文、密钥编号和设备等元数据；保留期可选 0（一直保留）、1、7 或 30 天，服务每小时清理到期且未置顶的条目，最多 50 条 |
| 社区皮肤、词库、快捷短语包、插件及收藏/评分 | `api.msime.app` 的社区数据 | 发布和展示社区内容，保存你的收藏与评分 | 公开作品和互动不会按时间自动过期；删除作品或注销账号时按账号关联关系删除 |
| 自愿提交的语音样本（仅 App 开启贡献语音后产生） | `api.msime.app` | 改进语音识别 | 最长保留 180 天，或在注销账号/删除语音数据分区时提前删除 |

登录挑战过期后会在每小时清理任务中删除；撤销的会话立即失效，过期会话及其摘要在清理任务中删除。账号资料、同步数据和社区数据没有统一的“几天后自动删除”期限。服务文档只规定在线数据库的删除行为，没有公布备份副本的统一保留期限；备份副本按部署方的备份策略处理。

退出、关闭同步和注销账号的效果不同：

- **退出登录**：官网请求服务端结束当前网页登录会话，然后清除本站的两个会话 Cookie 和浏览器中的登录提示。账号资料、同步内容、社区作品和其他设备的会话都会保留；如果要退出所有设备，需要在 App 的账号页管理会话。
- **关闭云剪贴板同步**：服务端立即删除云剪贴板条目、当前密钥、密钥封装和已登记的同步设备；不会操作设备本地的系统剪贴板。再次开启后，需要设备重新登记并生成新的密钥；保留天数设置继续保留。
- **注销账号**：官网目前引导你到水杉输入法 App 的账号页操作，注销需要最近一次重新登录确认。注销会删除账号、已绑定身份、所有会话和登录挑战，并按关联关系删除个人同步数据、云剪贴板密钥材料、社区作品及收藏/评分、自定义头像、反馈和语音贡献。这个操作不会删除你的 Google、Apple、华为账号、邮箱或手机号账号本身。在线数据库删除完成后，备份副本的清理时间仍取决于部署方的备份策略。

## 官网反馈表单

提交表单时，文字、截图及自愿填写的联系方式会经 Cloudflare Pages 转交 GitHub，公开发布为对应仓库的 Issue。无需 GitHub 账号，联系方式也可以全部留空。提交前可预览公开内容，请先遮挡截图中的个人信息，不要填写密码、API 凭据或不愿公开的输入记录。

表单使用 Cloudflare Turnstile 减少自动化垃圾提交，验证组件会与 Cloudflare 通信。验证令牌仅用于服务端校验，不写入 Issue；GitHub 提交凭据保存在服务端。
