# 隐私说明

本页说明输入法的本地数据、联网功能，以及浏览官网和提交反馈时涉及的数据。各平台的功能与默认设置不同，请查看你所用平台的说明。

## 本地输入与联网功能

拼音转换、候选排序和词频学习在本机完成。云候选、AI 联想、在线翻译、云端语音识别、匿名使用统计、账号和更新检查可能联网，具体取决于平台与设置。

| 功能 | Windows | macOS | Linux |
| --- | --- | --- | --- |
| 云候选 | 默认开启，首次安装可取消勾选 | 新装默认关闭，首次激活时询问，默认不启用 | 新装默认关闭，首次配置时询问，默认不勾选 |
| AI 候选联想 | 配置有效凭据后可用 | 填写自己的密钥后才联网 | 默认关闭，需配置服务 |
| 候选翻译 | 在线翻译需配置腾讯云凭据 | 默认不联网，需在设置中选择翻译服务 | 默认不联网，需在设置中选择翻译服务 |
| 语音输入 | 需配置服务并主动触发 | 主动触发，可选云端服务、本地模型或系统识别 | 主动触发，可选云端服务或本地模型 |
| 匿名使用统计 | 不发送 | 默认开启，可关闭 | 默认开启，可关闭 |
| 检查更新 | 手动点击时联网 | 手动点击时联网 | 手动点击时联网 |

Windows 的部分联网功能开关默认开启，但随包凭据为占位符；在填入有效凭据前，AI 联想、在线翻译和语音服务不会因此发出请求。云候选不需要 API 凭据。

## 会向服务商发送什么

- **云候选**：开启后向 Google input-tools 服务发送当前输入的拼写，以获取额外候选。该请求不包含已提交的正文、词库或学习记录。Windows 默认开启；macOS、Linux 与移动端新装默认关闭，需要你在首次询问或设置中打开，升级沿用已有设置。
- **AI 联想**：向配置的服务商发送拼写及功能所需的上下文。Linux 会附带当前输入框里最近由输入法上屏的文字（最多 1 KB），切换焦点或在密码等私密输入框中时清空。
- **在线翻译**：向所选翻译服务发送需要翻译的候选文本。选择「水杉账号」时，当前页的中文候选词会发送到水杉服务（api.msime.app）；各平台新装都不默认选中它，只有你主动选择才发送，升级沿用已有设置。本地词典翻译不需要联网。
- **云端语音识别**：向所选服务发送录音。若开启文字润色，识别结果还会发送到配置的文字服务。
- **匿名使用统计**：macOS、Linux、iOS、Android 与 HarmonyOS 默认向水杉服务（api.msime.app）发送每天一条活跃记录、会话记录和崩溃时的错误摘要与调用栈，附带平台、版本号和一个随机生成的安装编号，不含输入内容、候选、剪贴板、账号或硬件信息。桌面版可在设置「关于 → 许可与隐私 → 匿名使用统计」关闭，移动端在 App 的关于或设置页中关闭，关闭后同时清空本机待发送的记录。Windows 版不发送统计。
- **匿名账号**：macOS、Linux 与移动端在安装后首次启动时（Linux 在安装或首次配置时），用本机随机生成的标识和口令向水杉服务注册一个匿名账号，供候选翻译等功能使用，不发送输入内容或设备信息。
- **服务公告**：打开设置窗口时读取一次公告列表，不带凭据和安装编号。
- **更新检查**：Windows 请求本站的更新清单；macOS 与 Linux 在点击「检查更新」时请求 GitHub Releases 接口。

选择本地模型时，音频在本机识别，只有在设置中下载模型时会从 GitHub（或你配置的镜像）下载文件；但如果同时开启在线文字润色，识别出的文字仍会发送到润色服务。第三方服务通常也能获得 IP 地址和常规请求信息，后续处理与保存方式以其隐私政策为准。

## 如何减少联网

- **Windows**：在“设置 → 输入”中关闭云候选，并关闭 AI 辅助、在线翻译与语音输入。更新检查仅在主动点击时进行。
- **macOS 与 Linux**：新装时云联想已关闭、翻译服务未选择；若曾打开，在设置中关闭云联想与 AI 联想，翻译服务改选「不使用在线翻译」，并在「关于 → 许可与隐私」中关闭匿名使用统计。需要语音输入时选择本地模型并关闭在线文字润色（macOS 的设置步骤见 [macOS 语音输入指南](/docs/macos-voice/)）。

配置文件与具体操作见各平台[使用指南](/docs/windows/)及下方的原始隐私说明。

## 本机数据与 API 凭据

设置、学习记录和用户词库保存在当前用户目录，受该账号的文件权限保护。备份、同步或分享这些文件前，请检查是否包含个人词条、日志或服务凭据。

- **Windows**：数据位于 `%LOCALAPPDATA%\metasequoiaime\`；API 凭据以明文保存在 `config.toml` 中。
- **macOS**：设置与数据位于 `~/Library/Application Support/app.msime.macos/`，账号会话保存在其中仅本人可读写的 `account-session.json`。
- **Linux**：配置和数据位于 `~/.config/msime-client/` 等用户 XDG 目录；服务商凭据和账号会话保存在仅当前用户可读写的文件中，不加密。

剪贴板历史默认关闭，开启后会在本机保存复制内容。请勿公开分享含凭据的配置文件。

各平台对日志、学习记录及数据清理的具体行为，请以原始隐私说明为准；官网访问和反馈表单另按下文处理。

## 浏览官网

官网通过 Cloudflare 提供服务，页面请求会涉及 IP 地址和常规访问、安全处理信息。社区统计由本站提供，贡献者头像从 GitHub 加载。点击第三方链接后，将进入相应网站。

点击下载页的「蓝奏云盘」链接时，浏览器会向水杉服务（api.msime.app）发送一条匿名下载计数，内容只有平台（Windows）、版本号、安装包文件名、渠道（蓝奏云盘）和一个每次点击随机生成的编号，不含 Cookie、账号或设备标识；请求本身会经过服务器，因此服务器会看到 IP 地址，但不随计数保存。点击 GitHub 下载按钮不会发送任何计数。

页面顶部的公告由本站从水杉服务读取后显示，读取时不发送访客信息。关闭某条公告后，它的编号保存在本机浏览器中，用于不再显示这条公告，不会上传。

## 官网账号

在官网用 Google 账号登录后，登录状态保存在两个仅限本站读取的 HttpOnly Cookie 中：访问凭证 15 分钟过期，会话最长保留 30 天，网页脚本读不到它们。你对社区内容的收藏和评分，以及在「我的」页面管理的皮肤、词库、快捷短语和云剪贴板，保存在水杉服务（api.msime.app）你的账号下；云剪贴板最多保留 50 条，关闭同步会删除服务器上的全部记录。

## 官网反馈表单

提交表单时，文字、截图及自愿填写的联系方式会经 Cloudflare Pages 转交 GitHub，公开发布为对应仓库的 Issue。无需 GitHub 账号，联系方式也可以全部留空。提交前可预览公开内容，请先遮挡截图中的个人信息，不要填写密码、API 凭据或不愿公开的输入记录。

表单使用 Cloudflare Turnstile 减少自动化垃圾提交，验证组件会与 Cloudflare 通信。验证令牌仅用于服务端校验，不写入 Issue；GitHub 提交凭据保存在服务端。
